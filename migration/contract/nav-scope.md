# React port scope: what the navigation reaches

Generated by `migration/bin/nav-inventory.php`.

The scope of the React port is what a user can navigate to, not every route:
3,462 routes exist, 419 of them have no controller in either tree, and most of the
rest are reached by a link inside a page rather than from the menu. This is the
checklist a module is measured against.

Read statically from `Appearance\Menu\Builder`, because the builder branches on the
signed-in user's roles and the tenant's enabled modules - booting it shows one
tenant's slice, and the union is what has to be built.

Two kinds of declaration are excluded and listed at the end: items inside comments,
and items in builder methods nothing calls. Both look like navigation when the file
is read line by line, and neither is reachable by any user.

The fourth column is the role guard an item sits under: `|` is a choice within one
`if`, `AND` is a nested one, and `-` means any authenticated user sees it. Read from
the braces rather than the lines, which is why this is tokenised.

- navigation items linking to a route: **383**
- headings and dropdown parents (not screens): 135
- resolving to a controller: **335** across **18** modules
- naming a route that does not exist: 48

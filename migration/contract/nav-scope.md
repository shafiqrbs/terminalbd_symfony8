# React port scope: what the navigation reaches

Generated by `migration/bin/nav-inventory.php`.

The scope of the React port is what a user can navigate to, not every route:
3,462 routes exist, 419 of them have no controller in either tree, and most of the
rest are reached by a link inside a page rather than from the menu. This is the
checklist a module is measured against.

Read statically from `Appearance\Menu\Builder`, because the builder branches on the
signed-in user's roles and the tenant's enabled modules - booting it shows one
tenant's slice, and the union is what has to be built.

- navigation items linking to a route: **472**
- headings and dropdown parents (not screens): 142
- resolving to a controller: **365** across **19** modules
- naming a route that does not exist: 107
